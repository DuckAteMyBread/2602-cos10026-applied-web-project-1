# COS10026 Web Technology Project

## Scenario
A tourism and travel technology platform needs a website to advertise job vacancies. The website must contain the following four connected pages:
* [Home](index.html)
* [Job Description](jobs.html)
* [Apply](apply.html)
* [About](about.html)
