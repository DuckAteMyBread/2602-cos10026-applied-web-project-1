Junior Web Developer

#WD2026

Join our development team to build and maintain responsive, accessible websites and web applications for our clients.

Salary

$65,000 - $75,000

Reporting line

Reports to: Lead Web Developer

Key responsibilities

  • Develop and maintain HTML5 and CSS3 websites.
  • Implement responsive layouts for desktop and mobile devices.
  • Test websites for usability, accessibility and compatibility.
  • Collaborate with designers and other developers.
  • Identify and resolve website issues.

Essential Requirements

  1. Basic knowledge of HTML5 and CSS3.
  2. Understanding of responsive web design.
  3. Good problem-solving and communication skills.
  4. Ability to work effectively in a team.

Preferable Requirements

  1. Experience with Git and GitHub.
  2. Basic JavaScript knowledge.
  3. Familiarity with accessibility standards.

Cybersecurity Analyst

#CY2026

Help protect our digital systems and client websites by monitoring security risks, investigating incidents and supporting secure development practices.

Salary

$80,000 - $95,000 + superannuation

Reporting line

Reports to: Cybersecurity Manager

Key responsibilities

  • Monitor systems for potential security threats.
  • Assist with security assessments and vulnerability testing.
  • Investigate and document security incidents.

Essential Requirements

  1. Understanding of fundamental cybersecurity principles.
  2. Knowledge of common web security risks.
  3. Strong analytical and problem-solving skills.

Preferable Requirements

  1. A qualification in cybersecurity or information technology.
  2. Familiarity with OWASP security principles.
  3. Experience with security monitoring tools.
